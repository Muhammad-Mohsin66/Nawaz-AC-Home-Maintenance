# نواز لصيانة المكيفات والخدمات المنزلية — Nawaz AC & Home Maintenance
### منصة إلكترونية متكاملة للخدمات المنزلية بالرياض (MERN Stack)

مشروع متكامل تم بناؤه بأحدث تقنيات الويب لدعم خدمات التكييف، الكهرباء، السباكة، والصيانة المنزلية العامة في مدينة الرياض، وفق أعلى معايير الهوية المؤسسية والواجهات العربية (RTL).

---

## 🛠️ بنيان المشروع والتقنيات المستخدمة

- **الواجهة الأمامية (Frontend):**
  - **React 19** مع **Vite** لتجربة تصفح سريعة وفورية.
  - **Tailwind CSS v4** لتصميم عصري ودقيق متوافق مع اتجاه اليمين لليسار (`dir="rtl"`).
  - خطوط **Cairo** و **Tajawal** من Google Fonts.
  - **Framer Motion** لتأثيرات الحركة والتنقل السلس.
  - **Lucide React** لأيقونات حديثة ومتناسقة.

- **الخادم وقاعدة البيانات (Backend & Database):**
  - **Node.js** و **Express.js** لمعالجة الطلبات وواجهات البرمجة (REST API).
  - **MongoDB** مع **Mongoose ODM** لحفظ الحجوزات وإدارتها.
  - دعم الربط المحلي أو السحابي عبر **MongoDB Atlas**.
  - حماية المدخلات والتحقق من أرقام الجوال السعودية (`+9665xxxxxxxx` أو `05xxxxxxxx`).
  - معالجة مركزية للأخطاء وربط فوري ومباشر مع تطبيق واتساب (`WhatsApp API`).

## 🚀 دليل التشغيل على أجهزة macOS

### 1. تشغيل الخادم الخلفي (Backend Server)

افتح نافذة Terminal ونفذ الأوامر التالية:

```bash
cd "/Users/m.mohsin/Desktop/Nawaz webside/server"

# تثبيت الحزم (في حال لم تكن مثبتة مسبقاً)
npm install

# تشغيل الخادم في وضع التطوير
npm run dev
```

> **ملاحظة:** سيعمل الخادم تلقائياً على المنفذ `5001` (لتفادي تعارض خاصية AirPlay التابعة لنظام macOS على المنفذ 5000).  
> رابط فحص حالة الخادم: `http://localhost:5001/api/health`

### 2. إعداد قاعدة بيانات MongoDB

- **محلياً (Local MongoDB):**  
  تم ضبط الخادم افتراضياً للاتصال بقاعدة البيانات المحلية:
  ```env
  MONGO_URI=mongodb://127.0.0.1:27017/nawaz_maintenance
  ```
- **سحابياً (MongoDB Atlas):**  
  قم بتعديل ملف `server/.env` وضع رابط الاتصال الخاص بحسابك في Atlas:
  ```env
  MONGO_URI=mongodb+srv://<USERNAME>:<PASSWORD>@cluster0.xxxxx.mongodb.net/nawaz_maintenance?retryWrites=true&w=majority
  ```

### 3. تشغيل الواجهة الأمامية (Frontend)

في نافذة Terminal ثانية:

```bash
cd "/Users/m.mohsin/Desktop/Nawaz webside/client"

# تشغيل خادم التطوير السريع
npm run dev
```

افتح المتصفح على الرابط:
`http://localhost:5173`
